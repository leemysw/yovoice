# AI 服务

[English](ai.md) | **简体中文**

yovoice 可以选择接入大模型。配置 AI 服务后，右下角的“创作助手”面板可以用对话完成创作：新建和修改作品、写谱写词、改台词、配音色、发起语音、音乐或配乐生成，操作即时反映到界面。不配置也不影响其他功能。

## 添加服务

打开“设置 › AI 服务”。左侧列出已添加和可添加的服务，选中后在右侧直接填写：

| 服务 | 地址 | 密钥 |
| --- | --- | --- |
| 按量 API：DeepSeek、通义千问（百炼）、智谱 GLM、Kimi、豆包（火山方舟）、MiniMax、OpenAI、Anthropic、OpenRouter、OrcaRouter | 内置 | 需要；“从 … 获取 API 密钥”打开对应控制台 |
| 编程套餐：Kimi Code、智谱 GLM Coding Plan、百炼 Token Plan、MiniMax Token Plan、火山方舟 Coding Plan | 内置（套餐专用地址） | 需要套餐的密钥，与按量 API 的密钥不通用 |
| Ollama、LM Studio | 默认本机（`127.0.0.1`），可修改 | 通常不需要 |
| ChatGPT (Codex) | 本机的 Codex CLI | 不需要；通过 Codex 用 ChatGPT 登录 |
| 自定义 | 任意兼容地址 | 可选 |

OrcaRouter 提供免费模型，而且不用复制密钥：点“免费连接 OrcaRouter”（在设置里的 OrcaRouter 页），在浏览器登录 OrcaRouter 并同意授权。yovoice 在本机（`127.0.0.1`）接收密钥，自动添加服务、使用免费模型 `orcarouter/free` 并立即启用。免费模型高峰期可能限流，稍等一会儿重试或换一个模型即可。

**ChatGPT (Codex)** 通过官方 [Codex CLI](https://github.com/openai/codex)（`npm i -g @openai/codex` 或 `brew install codex`）使用你的 ChatGPT 订阅。设置页显示 Codex 是否已安装和登录；“用 ChatGPT 登录”会运行 `codex login`，在浏览器中完成后点“检测”。yovoice 不读取也不保存你的登录凭证。每次请求都在空的临时目录里以只读沙箱运行 `codex exec`，并忽略 `~/.codex/config.toml`，你为编程配置的模型、MCP 服务和钩子不会生效。保存服务时会读取 Codex 的模型列表并选中第一个。请求比 API 调用多几秒，并计入订阅的用量额度。

自定义服务可选择三种协议：OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages，并填写模型列表路径（如 `/models`；服务没有模型列表时留空，直接填写模型名）。

填写模型名，或“同步模型列表”后从列表中点选；“添加服务”或“保存更改”后，“测试”会发送一条简短消息，检查地址、密钥和模型。第一个添加的服务自动使用，在列表中标为“使用中”；有多个服务时，在写谱、写歌输入栏左下角的模型下拉里切换服务和模型。已保存的密钥只显示掩码，可“更换密钥”或“清除密钥”。

## 数据去向

- 请求从本机直接发往你选择的服务，使用“设置 › 常规”中的代理，未配置代理时沿用系统代理；本机地址不走代理。
- 密钥保存在数据目录数据库 `yovoice.db` 的私有表中（权限仅限本人，`0600`），不会出现在发给界面的状态里；设置页只显示掩码，删除服务会同时删除密钥。
- 发送的内容是你写的需求，以及一段说明乐谱或歌词格式的固定提示词。错误信息在显示和写入日志前会去掉密钥。

## 助手面板

点右下角的 **Ocho** 按钮、标题栏的助手按钮，或按 **⌘J / Ctrl+J** 打开面板；面板浮在右下角，放大后仍是浮层。直接说要做什么——“新建一个编曲作品，写四小节钢琴旋律”“给这个故事的角色逐个配音色”“生成这段旁白”——助手就会在应用里动手：作品建好即打开，写内容时编辑器即时更新，生成也走应用现有的流程。回复逐字流式输出；思考和每一步操作收在回复上方一行可展开的过程里，运行中展开、结束后收起，生成好的音频可直接播放，回复可一键复制。一轮进行中再发的消息会排队。点面板标题切换历史会话：可新建、切换、删除，每个会话有独立的上下文，最多保留 50 个会话、每个 200 条消息。

每条消息都附带当前页面、打开的作品、编辑区里选中的文字或台词、播放位置、作品所用模型是否已安装、最近一次生成的结果与错误码，以及记住的偏好，助手据此找到操作对象；选中的文字会以引用显示在输入框上方，点 × 可以不带。助手熟悉各个模型、页面与设置的位置和错误码的处理办法，可以查看已装模型、推理引擎、进行中的任务和最近的错误日志（已脱敏）来排查问题。

删除作品、生成记录或声音，下载模型或推理引擎，清理存储，切换计算设备或下载源，助手只会提议：对话里出现确认卡片，点确认才执行，执行走与界面按钮相同的流程；导入导出仍由你在界面里操作。你在对话里说出的长期偏好（常用声音、风格、语速等）会被记下，之后每次对话都会带上，可在“设置 › Ocho”中查看和删除。生成完成或失败、模型下载结束时，助手会在右下角给出建议，点一下即交给它处理；不需要时可在“设置 › Ocho”中关闭主动提示。

助手进程只开放 yovoice 自己的工具和随包的知识（Skill），不能执行命令、读写文件或联网，也不使用 ocho 的自动记忆与子 agent。

## AI 写谱、写词与改旋律谱

AI 写作统一走助手，编辑器里不再有单独的写作栏。在编曲或音乐作品里打开助手说出需求即可：助手读取作品，写出编曲（与手写乐谱同一套校验，不通过会自行修正）、风格、歌词与标题，或 YuE2 的旋律谱（按 YuE2 的 ABC 方言校验，出错时按小节自行修正），直接写进作品；想改就在面板里继续说。模型越强，编曲越好；较小的本地模型可能通不过检查。

## 限制

- 同一时间只运行一轮对话，可随时停止；单轮默认 10 分钟，可在设置中调整。会话记录重启后仍在。
- 浏览器预览模拟对话流程，真实调用模型需要桌面应用。
- 尚未在每个内置服务上逐一实测；服务拒绝请求时，错误信息会显示 HTTP 状态和原因。
